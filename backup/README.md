# 💾 النسخ الاحتياطي الأوتوماتيكي

كل يوم الساعة 3:17 الفجر (بتوقيت السعودية) GitHub بيعمل نسخة كاملة من:

- **قاعدة البيانات** كلها: الساكنين، الأرشيف، التايم شيت، الوجبات، السيارات، المعدات، الغرف، المستخدمين، الإعدادات، وقواعد الأمان
- **الصور والملفات**: صور الإقامة، وصور وملفات المعدات

النسخة **متشفّرة بباسورد إنت بس اللي تعرفه** (لأن الريبو عام)، وبتفضل محفوظة **90 يوم**.

---

## التجهيز (مرة واحدة)

ضيف 4 secrets في GitHub:
**الريبو ← Settings ← Secrets and variables ← Actions ← New repository secret**

| الاسم | تجيبه منين |
|---|---|
| `SUPABASE_URL` | Supabase ← Project Settings ← Data API ← **Project URL** |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase ← Project Settings ← API Keys ← تبويب **Legacy API Keys** ← **service_role** (دوس Reveal وانسخه) |
| `SUPABASE_DB_URL` | Supabase ← زرار **Connect** فوق ← **Session pooler** ← انسخ الرابط، وحط باسورد قاعدة البيانات مكان `[YOUR-PASSWORD]` |
| `BACKUP_PASSWORD` | باسورد قوي **إنت تختاره**. اكتبه في مكان آمن — **من غيره النسخ ملهاش أي لازمة** |

> ⚠️ مفتاح `service_role` وباسورد قاعدة البيانات بيفتحوا كل حاجة. متبعتهمش لحد ومتحطهمش في أي مكان غير GitHub Secrets.

## أول نسخة

**Actions ← نسخة احتياطية ← Run workflow ← Run workflow**

بعد دقيقتين تلاتة لازم تظهر ✅ خضرا، وتحت في **Artifacts** ملف اسمه `backup-التاريخ`.

## الاسترجاع

**Actions ← استرجاع نسخة احتياطية ← Run workflow**
- **run_id**: افتح تشغيل النسخة اللي عايزها، وانسخ الرقم اللي في آخر الرابط (`.../actions/runs/`**12345678**)
- **confirm**: اكتب `RESTORE`

⚠️ الاسترجاع **بيمسح البيانات الحالية** ويحط بيانات النسخة. لو حصل أي خطأ في النص، مفيش حاجة بتتغير.

بيشتغل كمان على **مشروع Supabase جديد فاضي**: غيّر الـ secrets لبيانات المشروع الجديد، شغّل الاسترجاع، وبعده شغّل `supabase/security.sql`.

## فتح النسخة على الكمبيوتر

1. نزّل الـ Artifact (هينزل zip)، وفكه هتلاقي ملف `.tar.gz.gpg`
2. **ويندوز**: سطّب [Gpg4win](https://gpg4win.org)، ودوس على الملف دبل كليك واكتب `BACKUP_PASSWORD`
3. هيطلع ملف `.tar.gz`، فكه بـ 7-Zip — هتلاقي:
   - `storage/` فيها كل الصور والملفات
   - `database.dump` قاعدة البيانات (بيرجّعها الاسترجاع)

## ملاحظات

- GitHub **بيوقف المواعيد الأوتوماتيكية** لو الريبو فضل 60 يوم من غير أي تعديل، وبيبعتلك إيميل قبلها. ساعتها ادخل **Actions ← نسخة احتياطية ← Enable workflow**.
- النسخ بتتمسح بعد 90 يوم. لو عايز تحتفظ بنسخة أطول (زي آخر الشهر)، نزّلها واحفظها عندك.
